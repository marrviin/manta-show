Why manta-show

为零干扰、可自动化的媒体捕获而设计

全部通过渲染层与 TTY 拦截采集,不需要人坐在电脑前,也不打扰正在运行的程序。

🖥️

零 OS 级录屏

全部经 Chromium 渲染层采集:无屏幕录制权限、无窗口抖动,CI 里也能跑。

⌨️

零侵入 CLI 捕获

TTY 文本流拦截回放,不改动你的 CLI 一行代码,产出即用的高清 mp4。

🎬

统一媒体管线

视频统一输出 mp4 (H.264),截图直接以 image content 返回,拿来即用。

🤖

面向 Agent 设计

会话式细粒度工具、可恢复的错误提示,返回体自带可插入 README 的 markdown 片段。

Install

一条命令,装好即用

自动检测本机已安装的 AI Agent(Claude Code、Cursor、Gemini CLI、Codex),把 manta-show 直接注册进它们的 MCP 配置。

安装 $ npx @manta-show/mcp init
体检 $ npx @manta-show/mcp doctor

装完后对 Agent 说一句「用 manta-show 录个演示」即可。源码方式安装见文档。

Capabilities

三条能力线,一套工具语法

网页、命令行、桌面应用 —— 同样的「打开 → 交互 → 录制」节奏。以下演示均由 manta-show 自己录制。

browser_*

网页

无头浏览器高清渲染,Agent 按可访问性快照自主定位元素、点击、输入、录屏。

  • 元素级与整页截图
  • 录制中继续交互
  • 可叠加 macOS 浏览器窗框
网页交互录制
终端命令录制
terminal_*

命令行

在 pty 中启动任意命令,Agent 读输出、程序化按键交互,对被录程序零侵入。

  • 读渲染后文本判断运行状态
  • 程序化输入与按键
  • 可叠加终端窗口装饰
electron_*

Electron 桌面应用

启动应用捕获主窗口,界面快照驱动交互,窗口与元素级截图。

  • 窗口 / 元素级截图
  • 可叠加 macOS 桌面壁纸装饰
  • 保持原始尺寸输出可选
