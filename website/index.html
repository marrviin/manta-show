Why manta-show4 reasons · 0 permissions

为零干扰、可自动化的媒体捕获而设计

全部通过渲染层与 TTY 拦截采集,不需要人坐在电脑前,也不打扰正在运行的程序。

零 OS 级录屏

全部经 Chromium 渲染层采集:无屏幕录制权限、无窗口抖动,CI 里也能跑。

零侵入 CLI 捕获

TTY 文本流拦截回放,不改动你的 CLI 一行代码,产出即用的高清 mp4。

统一媒体管线

视频统一输出 mp4 (H.264),截图直接以 image content 返回,拿来即用。

面向 Agent 设计

会话式细粒度工具、可恢复的错误提示,返回体自带可插入 README 的 markdown 片段。

Install1 command · 4 agents detected

一条命令,装好即用

自动检测本机已安装的 AI Agent(Claude Code、Cursor、Gemini CLI、Codex),把 manta-show 直接注册进它们的 MCP 配置。

安装 $ npx @manta-show/mcp init

装完后对 Agent 说一句「用 manta-show 录个演示」即可。源码方式安装见文档。
