简介

manta-show 是为 AI Agent(Cursor、Claude Code 等)定制的全场景产品媒体捕获 MCP Server。通过代码级控制,自动为网页、Electron 桌面应用、CLI 工具生成高画质截图与视频(mp4),用于快速补齐网站和 README 文档。

  • 零 OS 级录屏 —— 全部通过 Chromium 渲染层(Playwright / CDP)采集,无屏幕录制权限、无窗口抖动,CI 可跑
  • 零侵入 CLI 捕获 —— node-pty 拦截 TTY 文本流,在 xterm.js 回放页中渲染后录制,产出 mp4
  • 统一媒体管线 —— 所有视频统一为 mp4 (H.264, yuv420p);截图直接以 MCP image content 返回
  • 面向 Agent 设计 —— 会话式细粒度工具、可恢复的错误提示、返回体自带 markdown 引用片段

安装

要求:Node ≥ 20、pnpm。

安装与构建
# postinstall 会自动执行 playwright install chromium
git clone <this-repo> && cd manta-show
pnpm install
pnpm build
node-pty 说明:CLI 捕获依赖 node-pty(native 模块)。macOS 26 上 1.1.0 正式版有 posix_spawnp failed 兼容问题,本仓库固定使用 1.1.0-beta34。pnpm 安装时如提示构建脚本许可,确认 allowBuilds 中的 electron / node-pty / ffmpeg-static 为 true(见 pnpm-workspace.yaml)。

ffmpeg

录制视频需要 ffmpeg,按以下顺序自动定位:

  • 环境变量 MANTA_SHOW_FFMPEG 指定的路径
  • PATH 上的 ffmpeg
  • 依赖自带的 ffmpeg-static 全静态构建(默认可用,无需额外安装)
注意:Playwright 自带的 ffmpeg 是裁剪版(无 libx264),不能用于本项目。

接入 MCP 客户端

Claude Code 在项目级 .mcp.json 或 ~/.claude.json 中配置;Cursor 在 ~/.cursor/mcp.json 中使用同样结构。

懒人方式:运行 npx @manta-show/mcp init,自动检测已安装的 AI Agent(Claude Code、Cursor、Gemini CLI、Codex)并写入配置;遇到问题用 npx @manta-show/mcp doctor 体检修复。 
{
  "mcpServers": {
    "manta-show": {
      "command": "node",
      "args": ["/absolute/path/to/manta-show/packages/mcp/dist/index.js"],
      "env": {
        "MANTA_SHOW_OUTPUT": "/absolute/path/to/your-output-dir"
      }
    }
  }
}

环境变量

变量默认说明
MANTA_SHOW_OUTPUT~/.manta-show(用户目录下)媒体输出目录,需要产物进文档项目时指向它
MANTA_SHOW_FFMPEG自动定位指定 ffmpeg 可执行文件路径

网页捕获

基于 Playwright Chromium,无头运行,默认 2x 高清渲染(deviceScaleFactor=2,视口 1440×810)。

工具说明
browser_open打开网页,返回 sessionId(url, width=1440, height=810, deviceScaleFactor=2)
browser_navigate会话内跳转
browser_snapshot可访问性树快照,用于确定选择器
browser_click / browser_hover按 CSS 选择器点击 / 悬停
browser_type输入文本(可选回车提交)
browser_press_key / browser_scroll按键 / 滚动
browser_evaluate在页面执行 JS 表达式
browser_screenshot截图(selector 元素级裁剪,fullPage 整页),返回图片 + 路径
browser_record_start / browser_record_stop录制期间继续交互,stop 产出 mp4;见下方装饰选项
browser_close关闭会话

装饰选项

browser_record_stop 的 decorate 参数:

  • 'browser'(默认)—— 叠加 macOS 浏览器窗框(红绿灯 + 真实 URL 地址栏 + 圆角投影)
  • 'none' —— 原始画面

典型流程

browser_open → browser_snapshot 找选择器
→ browser_click / browser_type 交互
→ browser_record_start → 演示动作 → browser_record_stop 拿 mp4
→ 把返回体中的 markdown 引用片段插入 README

终端捕获

基于 node-pty + xterm.js 回放页,对被录程序零侵入。

工具说明
terminal_open启动命令并自动开始录制(command, args, cwd, cols=120, rows=30)
terminal_read读最近 N 行渲染后纯文本(去 ANSI),Agent 判断状态用
terminal_send / terminal_send_key输入文本 / 具名按键(enter、ctrl+c、上下左右……)
terminal_record_stop导出 mp4
terminal_stop / terminal_close结束进程 / 释放会话

装饰选项

terminal_open 的 decorate 参数:

  • 'terminal'(默认)—— 叠加终端窗口装饰(红绿灯 + 以命令为标题的标题栏)
  • 'none' —— 原始画面

Electron 捕获

基于 Playwright _electron API。

工具说明
electron_launch启动应用并捕获主窗口(app 为应用目录或入口 js)
electron_snapshot界面可访问性快照
electron_click / electron_type / electron_press_key界面交互
electron_screenshot窗口 / 元素截图
electron_record_start / electron_record_stop录制 / 导出 mp4;见下方装饰选项
electron_close关闭应用

装饰选项

electron_record_stop 的 decorate 参数:

  • 'desktop'(默认)—— 叠加 macOS 桌面装饰:窗口带圆角投影放在桌面壁纸上(无标题栏)。壁纸取自 macOS 26 (Tahoe) 官方壁纸,为 Apple 版权图像,仅供内部演示使用
  • 'none' —— 原始画面

视频输出规格

三类录制默认统一输出 1920×1080(16:9):等比缩放后居中补边(浏览器白底、终端深色底)。

  • 编码统一为 mp4 (H.264, yuv420p)
  • 录制中可以继续交互,stop 时一次性产出 mp4
  • *_record_stop 传 fit: 'native' 可保持录制原始尺寸

会话模型

  • 所有交互工具接受可选 sessionId
  • 不填时操作该类型最近活跃的会话,Agent 通常不需要手动传
  • 会话空闲 10 分钟自动回收

开发与测试

命令说明
pnpm devtsc --watch
pnpm test构建 + e2e(InMemoryTransport 直连,覆盖三条线)
pnpm test:unify统一输出规格的压力测试
pnpm startstdio 方式启动 server

e2e 会真实拉起 Chromium / pty /(若安装了 electron devDependency)Electron 应用,产物校验后输出到默认输出目录(可在测试环境变量中重定向)。

安全说明

browser_evaluate 会在页面上下文执行任意 JS,terminal_open 会在本机启动任意进程 —— 这是本工具的设计用途(本机开发 / 文档场景),请在信任的项目中使用。
