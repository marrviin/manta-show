简介

manta-show 是为 AI Agent(Cursor、Claude Code 等)定制的全场景产品媒体捕获 MCP Server。通过代码级控制,自动为网页、Electron 桌面应用、CLI 工具生成高画质截图与视频(mp4),用于快速补齐网站和 README 文档。

  • 零 OS 级录屏 —— 全部通过 Chromium 渲染层(Playwright / CDP)采集,无屏幕录制权限、无窗口抖动,CI 可跑
  • 零侵入 CLI 捕获 —— node-pty 拦截 TTY 文本流,在 xterm.js 回放页中渲染后录制,产出 mp4
  • 统一媒体管线 —— 所有视频统一为 mp4 (H.264, yuv420p);截图直接以 MCP image content 返回
  • 面向 Agent 设计 —— 会话式细粒度工具、可恢复的错误提示、返回体自带 markdown 引用片段

安装

要求:Node ≥ 20、pnpm。

安装与构建
# postinstall 会自动执行 playwright install chromium
git clone <this-repo> && cd manta-show
pnpm install
pnpm build
node-pty 说明:CLI 捕获依赖 node-pty(native 模块)。macOS 26 上 1.1.0 正式版有 posix_spawnp failed 兼容问题,本仓库固定使用 1.1.0-beta34。pnpm 安装时如提示构建脚本许可,确认 allowBuilds 中的 electron / node-pty 为 true(见 pnpm-workspace.yaml)。

ffmpeg

录制视频需要 ffmpeg,按以下顺序自动定位:

  • 环境变量 MANTA_SHOW_FFMPEG 指定的路径
  • PATH 上的 ffmpeg
  • ~/.manta-show/bin(init/doctor 下载)
  • 依赖自带的预编译平台包 @manta-show/ffmpeg-<platform>-<arch>(无 install 脚本,npm 12 默认屏蔽依赖脚本不影响)
网络受限环境:内置 ffmpeg 随 npm 包分发(npmmirror 自动镜像),安装无需访问 GitHub;仅在平台包未覆盖的环境上,跑一次 manta-show doctor 会自动从 npmmirror 镜像下载 ffmpeg 到 ~/.manta-show/bin。
注意:Playwright 自带的 ffmpeg 是裁剪版(无 libx264),不能用于本项目。

接入 MCP 客户端

Claude Code 在项目级 .mcp.json 或 ~/.claude.json 中配置;Cursor 在 ~/.cursor/mcp.json 中使用同样结构。

懒人方式:运行 manta-show init,自动检测已安装的 AI Agent(Claude Code、Cursor、Gemini CLI、Codex)并写入配置,随后完成环境准备:检测 Chromium / ffmpeg,缺失项一次性确认后带下载进度自动安装(走 npmmirror 镜像加速);遇到问题用 manta-show doctor 体检修复(含可选依赖如容器运行时的检查与安装指引)。 
{
  "mcpServers": {
    "manta-show": {
      "command": "npx",
      "args": ["-y", "@manta-show/mcp"]
    }
  }
}
全局安装过(npm install -g @manta-show/mcp):command 可直接用 manta-show、args 留空。从源码开发时,改为 command: "node" 指向 packages/mcp/dist/index.js 本地构建产物。环境变量均可不配,按需设置(见下表)。

环境变量(均可不配,按需设置)

变量默认说明
MANTA_SHOW_FFMPEG自动定位指定 ffmpeg 可执行文件路径

网页捕获

基于 Playwright Chromium,无头运行,默认 2x 高清渲染(deviceScaleFactor=2,视口 1440×810)。

工具说明
browser_open打开网页,返回 sessionId(url, width=1440, height=810, deviceScaleFactor=2)
browser_navigate会话内跳转
browser_snapshot可访问性树快照,用于确定选择器
browser_click / browser_hover按选择器点击 / 悬停(支持 CSS / text= / role= 等)
browser_type输入文本(可选回车提交)
browser_press_key / browser_scroll按键 / 滚动
browser_evaluate在页面执行 JS 表达式
browser_screenshot截图(selector 元素级裁剪,fullPage 整页),返回图片 + 路径
browser_record_start / browser_record_stop录制期间继续交互,stop 产出 mp4;start 传 steps 可批量执行编排动作并自动出片;见下方装饰选项
browser_close关闭会话

装饰选项

browser_record_stop 的 decorate 参数:

  • 'browser'(默认)—— 叠加 macOS 浏览器窗框(红绿灯 + 真实 URL 地址栏 + 圆角投影)
  • 'none' —— 原始画面

典型流程

browser_open → browser_snapshot 找选择器
→ browser_click / browser_type 交互
→ browser_record_start → 演示动作 → browser_record_stop 拿 mp4
→ 把返回体中的 markdown 引用片段插入 README

终端捕获

基于 node-pty + xterm.js 回放页,对被录程序零侵入。

工具说明
terminal_open启动命令并自动开始录制(command, args, cwd, env, isolation, image, cols=120, rows=30);isolation: 'container' 在一次性 Docker 容器中运行,与宿主完全隔离、退出即销毁,重复演示始终是真实的首次执行
terminal_read读最近 N 行渲染后纯文本(去 ANSI),Agent 判断状态用
terminal_send / terminal_send_key输入文本 / 具名按键(enter、ctrl+c、上下左右……)
terminal_wait阻塞等待输出中出现指定文本(子串匹配)或超时,附最近输出——比反复 terminal_read 轮询省轮次
terminal_record_stop导出 mp4
terminal_stop / terminal_close结束进程 / 释放会话
两种用法,语义不同:open 直接运行命令(如 command: "npm")只录输出,命令本身不出现在画面中,适合一次性 CLI / CI 场景;要演示"命令被敲入并执行",先 open 交互 shell(bash -i)再用 terminal_send 发送命令,输入由 TTY 回显进画面,效果与真人操作一致。按命令行为选隔离:自包含命令(安装、构建、demo CLI)和操作某个项目目录的命令(scaffold、build、lint 等,cwd 指向样例项目即可,产物落回宿主)用 isolation: 'container',既真实又可复现,且不会把真实项目/配置录进画面;读写用户真实环境的命令(如 init 写 ~/.claude.json)必须在宿主运行,重复演示可用 env: { HOME: "/tmp/demo-home" } 指向预构造标记文件的一次性目录,不碰真实配置。
重复演示与状态隔离:CLI 的所有状态都落在文件系统上,重复录制同一条命令会因上次残留(已安装、文件已存在、缓存命中)而走样。terminal_open 传 isolation: 'container'(配 image 锁版本,如 node:22)即可让命令在一次性 Docker 容器中运行:与 CI 的临时环境同一机制,命令及其全部状态变化与宿主完全隔离,容器退出即销毁,每次录制都是真实的首次执行,宿主零污染。传 cwd 时该目录挂载到容器 /workspace(CLI 生成的文件可从宿主查看),不传则容器文件系统自包含。需要本机有 Docker 或 Podman(macOS 推荐 OrbStack / colima;manta-show doctor 会检查并给出安装指引)。
容器环境按场景定制(isolation: 'container' 时):运行时用 image(python:3.12、golang:1.22…);模拟项目文件在宿主准备夹具目录后传 cwd;注入模拟的全局配置用 volumes(docker 语法,如 /tmp/demo-gitconfig:/root/.gitconfig);容器内预装依赖、造文件用交互 shell(bash -i + terminal_send),这些准备动作本身也是可录制的演示内容。

装饰选项

terminal_open 的 decorate 参数:

  • 'terminal'(默认)—— 叠加终端窗口装饰(红绿灯 + 以命令为标题的标题栏)
  • 'none' —— 原始画面

Electron 捕获

基于 Playwright _electron API。

工具说明
electron_launch启动应用并捕获主窗口(app 为应用目录或入口 js)
electron_snapshot界面可访问性快照
electron_click / electron_type / electron_press_key界面交互
electron_screenshot窗口 / 元素截图
electron_record_start / electron_record_stop录制 / 导出 mp4;start 传 steps 可批量执行动作并自动出片;见下方装饰选项
electron_close关闭应用

装饰选项

electron_record_stop 的 decorate 参数:

  • 'desktop'(默认)—— 叠加 macOS 桌面装饰:窗口带圆角投影放在桌面壁纸上(无标题栏)。壁纸取自 macOS 26 (Tahoe) 官方壁纸,为 Apple 版权图像,仅供内部演示使用
  • 'none' —— 原始画面

视频输出规格

三类录制默认统一输出 1920×1080(16:9):等比缩放后居中补边(浏览器白底、终端深色底)。

  • 编码统一为 mp4 (H.264, yuv420p)
  • 录制中可以继续交互,stop 时一次性产出 mp4
  • *_record_stop 传 fit: 'native' 可保持录制原始尺寸

会话模型

  • 所有交互工具接受可选 sessionId
  • 不填时操作该类型最近活跃的会话,Agent 通常不需要手动传
  • 会话空闲 10 分钟自动回收

安全说明

browser_evaluate 会在页面上下文执行任意 JS,terminal_open 会在本机启动任意进程 —— 这是本工具的设计用途(本机开发 / 文档场景),请在信任的项目中使用。
